v21.7.16

    seek URL if its embedded ctime is more than ~20s old. The proxy
    computed this once from a cached device-clock offset (confirmed via
    a live 403 from the CDN: "Encrypted URL age exceeded"); it now fetches
    server time fresh for every seek, matching the non-proxy path
